# 灵刃 VS 影狐

一个原创 2D 横版格斗小游戏原型，使用 HTML5 Canvas、CSS 和原生 JavaScript 制作。

游戏风格受到经典动漫格斗小游戏的启发，但角色、美术、场景和特效均为原创设计，没有使用现成动漫角色、图片或音频素材。

## 在线/本地运行

这是一个纯前端项目，不需要安装依赖。

直接用浏览器打开：

```text
index.html
```

也可以启动一个本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 游戏模式

- 单人模式：玩家控制灵刃剑士，影狐忍者由 AI 控制
- 双人模式：两名玩家使用同一个键盘本地对战
- 可随时点击页面按钮切换模式或重新开始

## 操作方式

### P1：灵刃剑士

| 操作 | 按键 |
| --- | --- |
| 左右移动 | `A` / `D` |
| 跳跃 | `W` |
| 格挡 | `S` |
| 冲刺 | `Space` |
| 轻攻击 | `J` |
| 重攻击 | `K` |
| 能量技 | `L` |

### P2：影狐忍者

| 操作 | 按键 |
| --- | --- |
| 左右移动 | `←` / `→` |
| 跳跃 | `↑` |
| 格挡 | `↓` |
| 冲刺 | `0` 或小键盘 `0` |
| 轻攻击 | `1` 或小键盘 `1` |
| 重攻击 | `2` 或小键盘 `2` |
| 能量技 | `3` 或小键盘 `3` |

### 通用

| 操作 | 按键 |
| --- | --- |
| 重新开始 | `R` |

## 技术说明

项目没有使用游戏引擎，主要逻辑都在 `game.js` 中：

- 使用 `requestAnimationFrame` 驱动游戏循环
- 使用矩形碰撞进行角色和攻击判定
- 使用 Canvas 绘制角色、场景、HUD 和粒子特效
- 使用简单状态机处理攻击、受击、格挡、冲刺和胜负
- 使用轻量 AI 控制单人模式中的影狐忍者
