# 灵刃 VS 影狐

一个原创 2D 横版格斗小游戏，使用 **Phaser 3 + Vite + TypeScript** 制作。

游戏风格受到经典动漫横版格斗小游戏的启发，但角色、美术、场景和特效均为原创设计，没有使用现成动漫角色、图片或音频素材。

## 技术栈

- Phaser 3：游戏场景、渲染、输入和动画循环
- Vite：本地开发服务器和打包
- TypeScript：游戏逻辑类型检查
- Canvas/WebGL：由 Phaser 自动选择渲染方式

## 如何打开游戏

先确认电脑已经安装 Node.js。

然后在项目目录运行：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

浏览器打开终端里显示的地址，通常是：

```text
http://127.0.0.1:5173/
```

如果想指定端口：

```bash
npm run dev -- --port 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 打包

生成生产版本：

```bash
npm run build
```

本地预览打包结果：

```bash
npm run preview
```

## 游戏模式

- 单人模式：玩家控制灵刃剑士，影狐忍者由 AI 控制
- 双人模式：两名玩家使用同一个键盘本地对战
- 可随时点击页面按钮切换模式或重新开始

## 开发说明

游戏目前没有使用外部图片素材，角色、背景、刀光、能量弹和粒子都由 Phaser Graphics 绘制。

这样做的好处是项目轻量、容易改颜色和动作，也方便后续替换成真正的精灵图、骨骼动画或瓦片地图。
